# MarketCode MCP: evidence-backed UK property answers in your AI assistant

We built MarketCode so your AI assistant can help you assess a UK property, not simply retrieve data.

Research what a home is worth, examine the comparable sales and adjustments behind the estimate, check how an asking price compares, and understand local prices, rents and yields with the supporting evidence.

Connect your assistant to MarketCode's hosted MCP server using OAuth sign-in.

Server: https://mcp.marketcode.ai/mcp  
Setup guides: https://marketcode.ai/data/mcp
